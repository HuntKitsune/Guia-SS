OBJETIVO: Asegurar que el usuario no pueda eliminar rastros durante la SS. REQUISITOS OBLIGATORIOS: • Pantalla completa compartida. • No minimizar sin autorización. • Mostrar bandeja del sistema. • Mostrar reloj y fecha del sistema. • Grabación activa durante toda la SS. IMPORTANTE: Muchos usuarios eliminan rastros en los primeros 30 segundos. El control inicial es una de las fases más importantes de toda la revisión.
OBJETIVO: Detectar elementos sospechosos rápidamente sin entrar aún en análisis profundo. Procesos Activos: tasklist /v Buscar: • Procesos con nombres genéricos. • Ejecutables en Temp o Roaming. • Nombres aleatorios. • Aplicaciones abiertas ocultas. Usuarios activos: query user Servicios activos/inactivos: sc query type= service state= all Rutas sospechosas: • AppData\Roaming\random123\ • Temp\asd9812\ • Carpetas recientes antes de jugar.
OBJETIVO: Encontrar archivos utilizados recientemente o rastros temporales. Descargas ordenadas por fecha: dir %userprofile%\Downloads /O:D Recientes del sistema: dir %appdata%\Microsoft\Windows\Recent Temp del usuario: %temp% Prefetch (MUY IMPORTANTE): C:\Windows\Prefetch ¿Por qué es importante? El Prefetch muestra programas ejecutados incluso aunque hayan sido eliminados posteriormente. Buscar: • Injectores. • Loaders. • Menús. • Cleaners. • DLL sospechosas.
Abrir: regedit Rutas clave: HKCU\Software\Microsoft\Windows\CurrentVersion\Run HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run Buscar: • Ejecutables en Temp. • Scripts ocultos. • Rutas con nombres random. • Programas iniciándose automáticamente. INDICADORES DE RIESGO: 🚩 Archivos sin fabricante. 🚩 Rutas ocultas. 🚩 Ejecutables recientes. 🚩 Nombres falsos de Windows.
Servicios deshabilitados: wmic service where startmode="disabled" get name Servicios inactivos: sc query state= inactive Buscar: • Antivirus deshabilitados. • Protecciones apagadas. • Servicios eliminados. • Drivers sospechosos. IMPORTANTE: Muchos cheats desactivan servicios de seguridad antes de ejecutarse.
